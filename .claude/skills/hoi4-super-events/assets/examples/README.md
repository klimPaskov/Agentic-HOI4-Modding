# Super Event visual references

These PNGs are composition and style references for the optional reusable Super
Events workflow. They are not runtime assets and must not be registered in a
project `.gfx` file.

The files were copied, at the maintainer's direction, from the tracked Chaos
Redux Super Event reference set at commit
`41044613ad6711dc39d9b7d0f12ac7100766b752`:

- `super_event_006_league_formation.png`
- `super_event_angelic_world_order.png`
- `super_event_angel_directorate.png`
- `super_event_divine_sovereignty.png`
- `super_event_world_in_fury.png`
- `contact_sheet.png`

The originating repository did not declare separate redistribution terms for
these files during this update. This note records lineage without asserting
rights that were not documented. New project art still needs its own source,
provenance, and rights record.
