# HOI4 Super Events Feature Assets

Use this selected-only add-on with `hoi4-super-events` and the generic `hoi4-feature-assets` skill. The generic skill owns source mode, image generation policy, provenance, processing, DDS conversion, manifests, and GFX handoff; this add-on narrows those rules to the installed presentation runtime.

## Required sources

Read the accepted presentation brief, the installed runtime skill, the relevant generic asset sections, the current runtime templates and dimensions, the owning GUI/GFX definitions, and only the project asset package named by the parent. Existing optional-package examples are composition references only and must never be restored, registered as project sprites, or presented as original art.

## Ownership

`hoi4_super_event_art_researcher` owns a bounded visual-direction and source-mode handoff. Use the generic asset workflow for final generation or archival sourcing when its specialist production is needed. The main agent owns final `.gfx`, GUI, scripted-localisation, gameplay, and registration wiring.

## Asset workflow

1. Define subject, role, tone, focal hierarchy, symbolism, safe text area, target dimensions, source mode, forbidden elements, and final sprite purpose.
2. Use sourced material when the image must depict a real person, photographed event, place, document, object, or archival artifact.
3. Use approved generation for fictional, alternate-history, symbolic, supernatural, or emotionally specific imagery that does not claim to be a real historical photograph.
4. Keep period technology, clothing, vehicles, architecture, and visual language aligned with the feature brief.
5. Preserve source files, processed previews, provenance, licenses, uncertainty, final DDS paths, and sprite handoff notes through the generic asset workflow.
6. Review the final image at runtime size and in the complete composition before the main agent wires it.

Do not use generated art as a placeholder for required real historical material. Do not invent public-domain status, licenses, dimensions, DDS settings, sprite names, file paths, or conversion commands. Do not copy event-specific content or identifiers from Chaos Redux.

## Dedicated art subagent

Spawn `hoi4_super_event_art_researcher` with `fork_context=false`. The parent prompt must include the stable registration ID, presentation role, owning caller, image role, source mode or decision question, target dimensions from the installed runtime, relevant reference paths, prohibited content, exact output paths, and handoff path.

The art subagent stays narrow. It may inspect named references, research a source direction, prepare a generation brief, and produce only the explicitly authorized image package. It does not edit `.gfx`, GUI, localisation, scripted localisation, event, sound, or gameplay files.

## Validation

Confirm that the final image has the correct dimensions and format, remains readable in the complete UI composition, matches the exact presentation role, uses the accepted source mode, has durable provenance, resolves through the proposed sprite handoff, and contains no placeholder, unrelated, copied, or falsely attributed material.

## Update triggers

Update this skill when runtime templates, dimensions, source-mode policy, art subagent ownership, processing, manifests, DDS handoff, or visual acceptance evidence changes.

## Completion standard

The main agent receives one final, provenance-backed, runtime-sized image package and can wire it without guessing source mode, dimensions, sprite intent, or acceptance criteria.
