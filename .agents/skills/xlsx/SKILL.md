# Spreadsheet workflow

Use this skill only when a repository actually maintains a spreadsheet or the user explicitly requests one. For delegated work, pair it with `hoi4_spreadsheet_doc_worker` and keep the handoff limited to named tabular files and named source data.

## Establish ownership first

Before editing, determine:

- the exact workbook, CSV, or TSV path
- whether the file is an editable source or a generated export
- which implementation, localisation, manifest, or specification owns mirrored values
- which sheets, tables, columns, formulas, and formatting are in scope
- whether macros, external links, named ranges, charts, validation rules, filters, hidden sheets, or protected cells must survive

Never infer that a CSV beside a workbook is independently editable. If the repository declares an exporter or a workbook source of truth, edit the source and regenerate the export through that declared command. Do not invent an exporter contract from filename similarity.

## Preserve existing workbooks

- Inspect the workbook's established styles, dimensions, merged cells, freeze panes, filters, print settings, number formats, and formula patterns before changing it.
- Match existing conventions. Do not restyle a maintained workbook unless the user requested a redesign.
- Use `openpyxl` for formulas and Excel-specific structure and `pandas` for bounded data analysis or plain table transforms.
- Never save a formula-bearing workbook after opening it only with `data_only=True`; that can discard formulas.
- Keep identifiers that may have leading zeroes, tags, localisation keys, dates used as labels, and other string-like codes explicitly typed as text.
- Make the smallest scoped edit and preserve unrelated sheets and records.

## Formulas and calculated values

Use spreadsheet formulas for values that are meant to remain dynamic. Do not calculate a total, percentage, ratio, lookup, or projection in Python and hardcode the result when the workbook convention expects a formula.

Keep assumptions in named or clearly labelled cells and reference them from formulas. Check range endpoints, one-based worksheet coordinates, cross-sheet quoting, empty denominators, and copied-formula offsets.

Every delivered workbook must have no visible `#REF!`, `#DIV/0!`, `#VALUE!`, `#N/A`, `#NAME?`, `#NULL!`, or `#NUM!` errors unless the user explicitly supplied and asked to retain a known error case.

## Recalculation

`openpyxl` writes formulas but does not evaluate them. If formulas were added or changed:

1. Confirm `soffice` is available on `PATH`.
2. Save the workbook.
3. From the repository root run:

```text
python .agents/skills/xlsx/recalc.py <workbook.xlsx> [timeout_seconds]
```

4. Read the JSON result. Fix every reported formula error and rerun until `status` is `success`.
5. Reopen the workbook with formulas preserved and sample-check the edited formulas, their dependencies, and their recalculated cached values.

The helper may install a LibreOffice Basic macro in the current user's LibreOffice profile. Run it only when workbook recalculation is authorized. If LibreOffice is unavailable, report recalculation as blocked; do not present stale cached values as current results.

## CSV and TSV work

- Detect and preserve delimiter, encoding, newline style, header spelling, column order, quoting, and stable row ordering unless the repository declares a canonical sort.
- Treat fields containing tags, keys, IDs, paths, scripted values, or localisation text as strings unless their schema says otherwise.
- Validate row counts, unique-key constraints, required columns, and any declared export equivalence after writing.
- If a workbook generates the delimited file, modify the workbook and use the repository exporter instead of patching the export.

## Verification checklist

- The edited file opens successfully.
- Only the requested files, sheets, ranges, or records changed.
- Formulas remain formulas and use the intended relative or absolute references.
- No formula errors remain after recalculation.
- Formatting, validation, filters, hidden content, macros, links, and charts required by the source survived.
- Mirrored player-facing text exactly matches its named localisation source.
- Generated exports were regenerated by the declared tool and match their source.
- The final report names any unavailable recalculation engine, unsupported workbook feature, or source conflict rather than guessing.
