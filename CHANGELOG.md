## 2026-11-06

Package release `package-2026-11-06`. HOI4 Agent Tools stays on 4.8.0 and HOI4 Live Tools on 1.3.0, the newest published versions.

- Move the `hoi4-imagegen` release route to v0.3.4. 0.3.3 lets the ChatGPT-login route run up to three requests at once across the machine and drop to one at a time after a sign-out, a rate limit or a usage-limit answer. 0.3.4 draws style references per request and per sub-family instead of one fixed set per family, keeps nation-specific art out of generic briefs, adds project style packs for a mod's own house style, measures agency upgrades, MIO traits, small icons, buildings, doctrines and per-family portrait backdrops from vanilla (DLC folders included), and treats the backend's "Unable to verify model access" answer as a transient error.
- Add unit types to the 3D pipeline (`.tools/3d_pipeline/config/unit_types.json`, #68): `infantry_melee`, `spearman`, `archer`, `heavy_brute`, `beast_biped`, `tree_creature`, `rider`, `mounted_archer`, `mount` and `quadruped_beast`. A job names one `unit_type` and gets its profile, rig route and the six land roles (idle, move, attack, defend, retreat, death). Every humanoid type uses one route (`continue_unit_humanoid`): prepare the body once, retarget each role's Meshy library clip with a provenance receipt, ground or seat the unit, export every role against one mesh, stage the runtime files and write the registration text for the unit's vanilla family.
- Add mounted units on the vanilla `units_cavalry.asset` pattern: a 27-bone `quadruped` creature rig with a non-deforming `Saddle_Node` and idle, walk, trot, gallop, charge, rear and collapse actions, and `hoi4_blender_seat_rider_action`, which keeps a rider's Meshy clip on the upper body and seats the pelvis on the mount. Creature routes now remesh the raw generation with Meshy (5 credits) and gate the remeshed model with the creature limits.
- Add `.tools/3d_pipeline/check_unit_files.py`. It reads the exported `.mesh`, `.anim` and `.dds` bytes without Blender and checks the engine limits from the game's `gfx/FX/pdxmesh.shader` (50 bones, 4 influences per vertex), the profile's triangle budget, animation joints, required roles and attach nodes, and texture format and mips. With `--mod-root` it also checks the mesh, animation, entity and sprite registration, and `--repair-textures` fixes shipped textures.
- Ship runtime unit textures as DXT5 with a full mip chain, the format of 736 of 743 vanilla unit textures, instead of single-level BGRA.
- Add `run_pilot.py --status`, which prints where each 3D job stands and the next command. The 3D bootstrap finds portable Blender builds and installs the pinned Blender 5.2.3 with winget when no supported build exists. Checkpoints are saved compressed without `.blend1` backups. The new `docs/3d-units.md` covers needs, costs, unit types, checks and failures.
- Fix the 3D candidate gate failing every new job with "welded ... not measured". Prepare's reopened geometry measurement now includes the welded topology the gate counts.
